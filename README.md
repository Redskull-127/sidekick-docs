# Sidekick docs

The documentation site for [Sidekick](https://github.com/Redskull-127/sidekick), a Claude Code mod: persona agents you can talk to.

Built with Next.js and [Fumadocs](https://fumadocs.dev). Content lives in `content/docs/*.mdx`.

```sh
bun install
bun run dev      # http://localhost:3000
bun run build
```

Deployed on Vercel at https://sidekick.meertarbani.in.
